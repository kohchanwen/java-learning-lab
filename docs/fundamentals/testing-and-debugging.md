# Testing and debugging

Status: not started.

## Prerequisites

Begin with language basics; practise throughout the roadmap.

## Learning sequence

1. JUnit assertions.
2. boundary and invalid inputs.
3. parameterized tests.
4. breakpoints.
5. stack traces.
6. behavior-preserving refactoring.

## Exercise

Write a JUnit test for a small method, practise debugging a failing assertion, then add boundary and invalid-input checks.

Put code in `src/main/java/learning/fundamentals/testing/` and matching tests
under `src/test/java/learning/fundamentals/testing/` as you implement it.

## Completion checkpoint

Reproduce a failure, locate its cause, and explain what each assertion guarantees.

## Exercise

Write a batch processor that consumes items of a declared type and rejects incompatible types at compile time.

Put code in `src/main/java/learning/fundamentals/generics/` and matching tests
under `src/test/java/learning/fundamentals/generics/` as you implement it.

## Completion checkpoint

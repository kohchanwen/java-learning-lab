Status: not started.

## Prerequisites

Methods and OOP; combine with I/O.

## Learning sequence

1. Checked and unchecked exceptions.
2. propagation and causes.
3. validation failures.
4. try-with-resources.

## Exercise

Parse a small input file and distinguish invalid records from an unreadable file without swallowing failures.

Put code in `src/main/java/learning/fundamentals/exceptions/` and matching tests
under `src/test/java/learning/fundamentals/exceptions/` as you implement it.

## Completion checkpoint

Report useful context, preserve causes where appropriate, and close resources on success and failure.

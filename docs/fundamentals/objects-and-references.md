# Objects and references

Status: not started.

## Prerequisites

Language basics.

## Learning sequence

1. Object creation and references.
2. null.
3. mutation and aliasing.
4. Java pass-by-value.
5. identity versus equality.

## Exercise

Predict and then run examples that mutate an object, reassign a parameter, and share one object between two variables.

Put code in `src/main/java/learning/fundamentals/basics/` and matching tests
under `src/test/java/learning/fundamentals/basics/` as you implement it.

## Completion checkpoint

Explain why a mutation can affect the caller while parameter reassignment does not.
